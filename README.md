## 🎶 Keyword 

<h3>What is this?</h3>
GregTech Universal Frame ( GTUF )  is a mod that depends on GregTechCEu:Modern.It is desighed to provide
a universal frame for modpack authors to develop their modpacks.
<h3>What does this mod include?</h3>
GTUF don't provide substantial content by itself.
Instead,it encourages modpack authors to use its methods and interfaces for an all-in-one modpack
development experience,whether In JAVA or via KubeJS <strong>( with a primary focus on KubeJS users )</strong>
<h3>What are the development plans?</h3>
GTUF is a continuously updated mod.The code comes partly from other open-source projects,and also from author's core_mod that are still under development for modpack.
